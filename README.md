# Facial Recognition Tool for Social Network Analysis

## Overview
This project implements a **facial recognition tool** that analyzes videos, detects faces, and generates PDF reports. The system features a user-friendly GUI and leverages advanced face detection techniques to enhance video analysis for social network insights.

## Key Achievements
- Developed and deployed a facial recognition system for social network analysis.
- Integrated **OpenCV**, **face-recognition**, and **PyQt5** for an intuitive and interactive interface.
- Utilized advanced face detection techniques for accurate and efficient video analysis.

## Contributions
- Designed a **GUI using PyQt5** for seamless video selection and analysis.
- Engineered a robust backend for facial recognition and automated **PDF report generation**.
- Strengthened tool security by incorporating known faces and real-time analysis capabilities.

## Repository Contents
- **`tool.py`**: Core Python script for GUI, facial detection, and report generation.
- **`FACE DETECTION TOOL.pptx`**: Presentation explaining project setup, workflow, and results.  
  *For any doubts or detailed understanding, please go through the attached PPT.*

## Technologies & Tools
- **Python**: OpenCV, face-recognition, PyQt5
- **PDF Reporting**
- **Video & Image Processing**
- **GUI Development**

## How to Run
1. Install dependencies listed in `requirements.txt`.
2. Run `tool.py` to launch the GUI.
3. Select a video to analyze.
4. Review the generated PDF reports for actionable insights.

## Outcome
- Enhanced accuracy and efficiency in facial recognition tasks.
- Enabled proactive analysis of social network videos.
- Delivered user-friendly reporting and real-time detection for better decision-making.
